# showcase-salon

A site on jtakeit, scaffolded by @jtakeit/astro.

```bash
npm ci            # the lockfile is pinned; npm install would drift it
npm run dev
npm run check
npx @jtakeit/astro catalogue   # write jtk/catalogue.json and check it against the build
```

What the platform expects of this repository is in `node_modules/@jtakeit/astro/docs/` once
the package is installed, and at https://github.com/jtakeit/jtakeit-kit.
